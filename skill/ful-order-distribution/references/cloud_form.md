# Форма реестра Cloud

Результат агента — лист «Новые строки Cloud» с 12 колонками строго в этом
порядке и с этими заголовками:

| № | Колонка | Что пишем | Формат |
| --- | --- | --- | --- |
| 1 | Заказ | номер заказа из комментария ФУЛ | `S0001234` |
| 2 | Поставщик | контрагент из 1С; написание приводится к тому, что уже есть в Cloud | текст |
| 3 | Бренд | бизнес-единица из 1С | текст |
| 4 | Логист | короткое имя как в Cloud (`Иванов А.П.`) или полное ФИО | текст |
| 5 | Статус | всегда `в работе` | текст |
| 6 | Дата подтверждения | не заполняется (подтверждения ещё не было) | ДД.ММ.ГГГГ |
| 7 | Cut-off | «Cut-off date» из ФУЛ, как есть | ДД.ММ.ГГГГ |
| 8 | Дата получения УЛ | дата ФУЛ | ДД.ММ.ГГГГ |
| 9 | Страна отправления | страна из ФУЛ; если пусто — `не определено` | текст |
| 10 | Способ доставки | `air`, `sea`, `truck`, `direct truck`, `railway` | текст |
| 11 | Документы получены | не заполняется | ДД.ММ.ГГГГ |
| 12 | Комментарий | пусто; для возможного пропуска — `Возможный пропуск: ФУЛ от ДД.ММ.ГГГГ` | текст |

## Правила заполнения

- Строка создаётся только для нового заказа. Повторные отправки, дубли внутри
  пачки и ФУЛ с неполными данными в этот лист не попадают.
- Старые заказы (уже имеющиеся в Cloud) в результат не переносятся.
- Заказ не может встречаться дважды.
- Значения не придумываются: если данных нет, пишется `не определено`
  (кроме случая «в группе нет доступных логистов» — там строка создаётся
  с `не определено` в колонке «Логист»).
- Логист пустым не остаётся: либо конкретное имя, либо `не определено`.

## Остальные листы результата

| Лист | Содержимое |
| --- | --- |
| Новые строки Cloud | строки по форме выше |
| Повторные отправки | ФУЛ, заказ, дата, логист и статус из Cloud, готовый комментарий «Повторная отправка ФУЛа, ДД.ММ.ГГГГ» |
| Возможные пропуски | ФУЛ, заказ, дата ФУЛ, последняя дата получения УЛ в Cloud, причина |
| Требует внимания | по одной причине на строку + что сделать человеку |
| Журнал решений | каждый ФУЛ пачки: тип, группа, логист, обоснование, флаг внимания |
| Сводка | счётчики для ответа в чате |
