# Агент распределения ФУЛ между логистами (GigaCowork)

Тестовое задание: агент принимает три выгрузки Excel (ФУЛ из 1С, реестр Cloud,
сотрудники 1С), сам определяет новые упаковочные листы, группу логистов
и логиста, и отдаёт файл по форме реестра Cloud плюс список того, что требует
решения человека.

Решения о статусе ФУЛ, группе и логисте принимает **детерминированный скрипт**
навыка. Языковая модель запускает скрипт и пересказывает результат — поэтому
агент не «фантазирует» и одинаково отвечает при повторных запусках.

## Что в репозитории

```
skill/ful-order-distribution/    навык в формате GigaCowork
  SKILL.md                       инструкция для модели (YAML + правила)
  scripts/ful_distribution.py    весь расчёт + запись result.xlsx
  references/rules.md            правила и допущения
  references/cloud_form.md       форма реестра Cloud
  references/dictionaries.md     синонимы заголовков, справочники
system_prompt.txt                системный промпт агента (не зависит от harness)
INSTALL.md                       установка и запуск
data/generate_data.py            генератор синтетических данных
data/*.xlsx                      три входных файла + эталон
tests/run_checks.py              3 прогона, метрики, проверка формы
tests/test_header_robustness.py  проверка на «чужих» файлах (порядок колонок, листы)
docs/REPORT.md / .pdf            отчёт: вопросы, алгоритм, допущения, метрики
dist/                            готовые архивы для сдачи
```

## Быстрый старт

```bash
python3 -m venv .venv && .venv/bin/pip install openpyxl xlrd
.venv/bin/python data/generate_data.py
.venv/bin/python skill/ful-order-distribution/scripts/ful_distribution.py \
  --files data/ful_1c.xlsx data/cloud_registry.xlsx data/staff_1c.xlsx --out out/run1
.venv/bin/python tests/run_checks.py --runs 3
```

Результат — `out/runN/result.xlsx` и короткая строка в консоли:

```
Готово: новых строк — 18, повторных отправок — 2, требуют внимания — 9.
```

## Метрики на синтетическом наборе (3 прогона)

| Метрика | Значение | Порог |
| --- | --- | --- |
| Совпадение с эталоном по всем полям | 24/24 (100%) | ≥ 95% |
| Точность: тип ФУЛ / группа / логист / комментарий | 100% / 100% / 100% / 100% | 100/100/95/100% |
| Выдуманные значения | 0 | 0 |
| Воспроизводимость | одинаковая | одинаковая |
| Время ответа на пачку | ≈ 1,4 с | ≤ 60 с |
| Устойчивость к другому порядку колонок и именам листов | результат идентичен | — |

## Формат сдачи

- `dist/agent_gigacowork.zip` — навык + системный промпт + инструкция;
- `dist/test_data.zip` — три файла Excel, эталон, генератор, скрипты прогонов;
- `docs/REPORT.pdf` — вопросы заказчику, алгоритм, допущения, метрики, лог прогона.

Подробности — в отчёте `docs/REPORT.pdf`.
