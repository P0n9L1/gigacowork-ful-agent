# Справочники

## Заголовки, которые узнаёт скрипт

Сопоставление идёт по названию колонки: нижний регистр, «ё» → «е», без
пунктуации и лишних пробелов. Достаточно любого из вариантов.

### Выгрузка ФУЛ

| Поле | Варианты заголовка |
| --- | --- |
| дата ФУЛ | `Дата`, `Дата и время ФУЛ`, `Дата отправки ФУЛ` |
| cut-off | `Cut-off date`, `Cut off`, `Cutoff`, `Катофф` |
| номер ФУЛ | `Номер`, `Номер ФУЛ`, `Номер упаковочного листа` |
| статус | `Статус` |
| комментарий | `Комментарий`, `Примечание` |
| способ доставки | `Способ доставки`, `Тип доставки`, `Вид доставки` |
| бренд | `Бизнес единица`, `Бренд`, `Торговая марка` |
| поставщик | `Контрагент`, `Поставщик` |
| страна | `Страна`, `Страна отправления` |

### Реестр Cloud

`Заказ`, `Поставщик` / `Контрагент`, `Бренд`, `Логист`, `Статус`,
`Дата подтверждения`, `Cut-off`, `Дата получения УЛ`, `Страна отправления`,
`Способ доставки`, `Документы получены`, `Комментарий`.

### Сотрудники

`Наименование` / `ФИО`, `Текущее состояние` / `Состояние`, `Должность`,
`Код` / `Табельный номер`.

## Способы доставки

| Канон | Синонимы |
| --- | --- |
| `air` | air, авиа, авиаперевозка, aviation |
| `sea` | sea, море, морская, ocean |
| `truck` | truck, авто, фура |
| `direct truck` | direct truck, прямой авто, прямая машина |
| `railway` | railway, rail, жд, ж/д, железная дорога |

## Страны, которые относятся к Китаю для правила ВЭД

Китай, China, CN, CHN, КНР, PRC, Гонконг, Hong Kong, HK, Макао, Macao, Macau.

## Должности → группа

| Должность (подстрока) | Группа |
| --- | --- |
| `авиа` | Авиаперевозки |
| `ВЭД` | ВЭД |
| `мультимодаль` | Мультимодальные перевозки |
| `ассистент`, `помощник`, `руководитель`, `начальник`, `директор` | не распределяет |

## Состояния сотрудников

| Состояние | Доступен |
| --- | --- |
| `Работает` | да |
| `Уволен …` | нет |
| `Отпуск …`, `Отпуск по уходу за ребёнком`, `Отпуск без сохранения з/п` | нет |
| `Больничный`, `Нетрудоспособен` | нет |
| пусто или неизвестное | нет (с причиной) |
